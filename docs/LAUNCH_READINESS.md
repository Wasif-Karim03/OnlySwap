Important: `supabase/config.toml` drives the local stack. It does not by itself prove any hosted setting. `scripts/deploy/staging-supabase.command` runs `supabase config push` (around `scripts/deploy/staging-supabase.command:87-104`) after regenerating the `[remotes.staging]` block. That push sends the `[auth]` settings from `supabase/config.toml` merged with the staging override: site URL and redirect URLs, Gmail SMTP on port 465 (user and password from env), the `[auth.rate_limit]` values (`email_sent = 200`, `sign_in_sign_ups = 30`, `token_verifications = 30`), `max_frequency = "60s"`, `otp_length = 6`, `otp_expiry = 600`, the three OTP templates and both Auth hooks. CAPTCHA is not pushed because the `[auth.captcha]` block is commented out (`supabase/config.toml:225-228`). I did not read the hosted Auth settings back from staging, so every hosted Auth value is unverified. No `[remotes.prod]` block exists, and production does not exist yet.

## 1. Verdict

OnlySwap is feature complete for R1.0 on staging, but it is not close to TestFlight. There is no production backend, no production build has ever been made, and most App Store Connect work is still owner work. A realistic path is about 24 ordered steps to the first TestFlight build and about 13 more to App Store submission. Most of them are owner account and dashboard steps that cost $0, but two may cost money (CSAM scanning may need a domain, and a lawyer review is not free). The top blockers are: (1) no production Supabase project, because the free plan's 2 active slots are taken by `intention` and staging, and there is no production deploy script or `[remotes.prod]` config; (2) the EAS `production` environment has no variables at all, so a production build would fail the env check in `apps/mobile/src/lib/env.ts`, and Sentry and PostHog have no production keys anywhere; (3) the iOS build path is unproven: local builds are broken on Xcode 27.1 with Swift 6.4, `apps/mobile/modules/app-transaction` has never compiled in the full app, and EAS has never run a `production` build; (4) 14 stacked draft PRs (#36 to #49) sit unmerged above main, with red `mobile` checks on #37 to #46 at their last run; (5) CSAM scanning is required before launch (DEC 137) and is not set up, and Cloudflare's free tool likely needs a custom domain (unverified); (6) account deletion leaves the person's Quad and chat photos behind (item 25), and App Store review requires full account deletion.
