# A. Security audit (OnlySwap, branch audit/production-readiness)

Scope: LOCAL Supabase only (pgTAP ran in a scratch clone DB `audit_sec` of the local DB, inside begin..rollback; nothing hosted touched). App code untouched.
Spec used: locked R1.0 (CLAUDE.md, SECURITY.md, DATA_MODEL.md). Anonymous buyer-seller chat, location and gamification are out of scope per owner.
Scripts: `audit/scripts/scan/run-security-scans.sh`, `audit/scripts/pgtap/{clone-db,build,run}.sh` + `sec_01..05_*.test.sql`. Raw: `audit/raw/sec-*`.
