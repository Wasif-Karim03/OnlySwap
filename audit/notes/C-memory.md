## Run it (device/simulator)
1. `brew install --cask temurin` (JRE for Maestro), build a release or dev client, start staging, export `REVIEW_PASSWORD`.
2. Terminal A: `bash audit/scripts/maestro/measure-memory.sh android 35` (or `ios`).
3. Terminal B: `maestro test audit/scripts/maestro/long-session.yaml -e REVIEW_PASSWORD=...`. First run `memory-smoke-3min.yaml`.
4. Pass criteria: PSS / footprint plateaus after ~minute 10 (< 1.5x growth to minute 35), Android Views and Activities counts flat, no JS heap growth > 30% between two forced-GC Hermes snapshots (instructions are in the script footer).
5. Watch specifically: `stores` Map and query cache (C-03/C-04), Inbox ScrollView, Campus feed, Photo grids.
